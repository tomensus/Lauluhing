# TikTok Photo Mode: „Mida isa tegelikult tahab?“ (isadepäev)

4 slaidi, 3:4 (1080×1440), tekst TikToki turvaalas. Allikas: `src/slides.html` (joonistused `tiktok-shared/crayon.js`, font `tiktok-shared/fonts/kalam.ttf`), eksport repo juurest: `node tiktok-shared/export.js isa-tahab`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Kriidijoonistuse stiil, lühike ja lihtne. Hinda ei näidata. Isadepäev on 8. novembril 2026.
