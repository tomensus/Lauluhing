# TikTok Photo Mode: isadepäev, kriidijoonistus

5 slaidi, 3:4 (1080×1440), tekst TikToki turvaalas. Allikas: `src/slides.html` (joonistused `tiktok-shared/crayon.js`, font `tiktok-shared/fonts/kalam.ttf`), eksport repo juurest: `node tiktok-shared/export.js isadepaev-kriit`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Kriidijoonistuse stiil (valge taust, värvipliiatsiga kritseldatud joonistused, vildikiri). Hinda ei näidata, ainult „praegu on soodushind“ ja üleskutse kirjutada. Isadepäev on 8. novembril 2026.

|---|----------|-----------|
