# TikTok Photo Mode: „Kõik need aastad ühes laulus“ (laul abikaasale, vanemale vaatajale)

6 slaidi, 3:4 (1080×1440), tekst TikToki turvaalas. Allikas: `src/slides.html` (joonistused `tiktok-shared/crayon.js`, font `tiktok-shared/fonts/kalam.ttf`), eksport repo juurest: `node tiktok-shared/export.js abikaasa`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Vanemale vaatajale: suur ja lihtne tekst, viisakas „teie“. Sama paar läbi aastate (kohtumine, kodu, lapsed, täna). Hinda ei näidata. Aastaarv ja „35 aastat“ on illustreerivad.
