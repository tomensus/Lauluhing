# TikTok Photo Mode: „Probleem? Lahendus.“

5 slaidi, 3:4 (1080×1440). Allikas: `src/slides.html` (joonistused `tiktok-shared/crayon.js`, font `tiktok-shared/fonts/kalam.ttf`), eksport repo juurest: `node tiktok-shared/export.js probleem-lahendus`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Formaat omaniku saadetud eeskuju järgi: iga slaid on kaheks jagatud, üleval probleem küsimärgiga (kurb tegelane), joon, all lahendus (rõõmus tegelane). Suure peaga kriidijoonistusega tegelane on joonistatud `src/slides.html` funktsioonis `bust()`. Hinda ei näidata.

| # | Üleval | All |
|---|--------|-----|
| 1 | Ei tea, mida kinkida? (käed peas, küsimärgid) | Kingi laul. (kõrvaklapid, pöial püsti) |
| 2 | Kingid kaovad kapi taha? (mõttemull: kink kapil) | Laul jääb alles. (laulukaart „Laul sulle“) |
| 3 | Raske öelda, mida tunned? (mõttemull „…“) | Ütle see laulus. (laulab, noodid) |
