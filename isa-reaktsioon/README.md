# TikTok Photo Mode: „Isa reaktsioon kingile“ (isadepäev)

6 slaidi, 3:4 (1080×1440), tekst TikToki turvaalas. Allikas: `src/slides.html` (joonistused `tiktok-shared/crayon.js`, font `tiktok-shared/fonts/kalam.ttf`), eksport repo juurest: `node tiktok-shared/export.js isa-reaktsioon`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Kriidijoonistuse stiil. Kolm tavalist kinki saavad viisaka vastuse, laul paneb isa vaikima. Hinda ei näidata. Isadepäev on 8. novembril 2026.
