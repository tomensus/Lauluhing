# TikTok Photo Mode: „Kui kaua sinu kink kestab?“

6 slaidi, 3:4 (1080×1440), tekst TikToki turvaalas. Allikas: `src/slides.html` (joonistused `tiktok-shared/crayon.js`, font `tiktok-shared/fonts/kalam.ttf`), eksport repo juurest: `node tiktok-shared/export.js kink-kestab`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Kriidijoonistuse stiil, üldine (sobib igal ajal). „Kestvused“ on nali, mitte väide. Hinda ei näidata.
