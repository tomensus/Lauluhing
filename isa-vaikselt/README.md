# TikTok Photo Mode: „Isa tegi seda kõike vaikselt“ (isadepäev)

6 slaidi, 3:4 (1080×1440), tekst TikToki turvaalas. Allikas: `src/slides.html` (joonistused `tiktok-shared/crayon.js`, font `tiktok-shared/fonts/kalam.ttf`), eksport repo juurest: `node tiktok-shared/export.js isa-vaikselt`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Kriidijoonistuse stiil. Lapsepõlvemälestused, mida iga laps ära tunneb: postitus, mida saadetakse õele-vennale või isale. Bränd ja hind alles viimasel slaidil. Isadepäev on 8. novembril 2026.

## Postituse tekst

> Saada see oma õele või vennale 🥹 Mida sinu isa vaikselt tegi? 👇
> #isadepäev #isa

## Kuidas postitada

1. Lisa TikToki äpis rahulik, soe, natuke nostalgiline heli (klaver või akustiline kitarr).
2. Postita õhtul (u 19–21). Kinnita oma kommentaar, nt „Minu isa soojendas talvel auto enne, kui ma välja tulin 🥹“.

## Avaldamise seaded (WoopSocial, TikTok)

```json
{
  "postType": "PHOTO",
  "postMode": "MEDIA_UPLOAD",
  "privacyLevel": "PUBLIC_TO_EVERYONE",
  "allowComment": true,
  "autoAddMusic": false,
  "isYourBrand": true,
  "isBrandedContent": false,
  "photoCoverIndex": 0
}
```
