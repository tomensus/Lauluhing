# TikTok Photo Mode: „Igas sõpruskonnas on need sünnipäevasõbrad“

6 slaidi, 3:4 (1080×1440), tekst TikToki turvaalas. Allikas: `src/slides.html` (joonistused `tiktok-shared/crayon.js`, font `tiktok-shared/fonts/kalam.ttf`), eksport repo juurest: `node tiktok-shared/export.js synnipaeva-sobrad`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Kriidijoonistuse stiil, üldine. Äratundmine ja sõprade märkimine kommentaarides; bränd ainult lõpus. Hinda ei näidata.
