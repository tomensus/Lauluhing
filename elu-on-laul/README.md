# TikTok Photo Mode: „Iga elu on laul“

6 slaidi, 3:4 (1080×1440), tekst TikToki turvaalas. Allikas: `src/slides.html` (joonistused `tiktok-shared/crayon.js`, font `tiktok-shared/fonts/kalam.ttf`), eksport repo juurest: `node tiktok-shared/export.js elu-on-laul`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Kriidijoonistuse stiil, üldine ja soe. Elu jutustatud laulu osadena. Hinda ei näidata.
