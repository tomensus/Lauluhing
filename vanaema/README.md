# TikTok Photo Mode: „Asjad, mida iga vanaema teeb“

6 slaidi, 3:4 (1080×1440), tekst TikToki turvaalas. Allikas: `src/slides.html` (joonistused `tiktok-shared/crayon.js`, font `tiktok-shared/fonts/kalam.ttf`), eksport repo juurest: `node tiktok-shared/export.js vanaema`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Kriidijoonistuse stiil, üldine. Äratundmine ja sugulaste märkimine; bränd ainult lõpus. Hinda ei näidata.
