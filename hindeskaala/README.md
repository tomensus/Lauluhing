# TikTok Photo Mode: „Jõulukingid hindeskaalal 1–10“

7 slaidi, 9:16 (1080×1920), tekst TikToki turvaalas. Allikas: `src/slides.html` (ühine stiil `tiktok-shared/lauluhing.css`), eksport repo juurest: `node tiktok-shared/export.js hindeskaala`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.
