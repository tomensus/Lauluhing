# TikTok Photo Mode: „Eesti isade 5 tüüpi“ (isadepäev)

7 slaidi, 3:4 (1080×1440), tekst TikToki turvaalas. Allikas: `src/slides.html` (joonistused `tiktok-shared/crayon.js`, font `tiktok-shared/fonts/kalam.ttf`), eksport repo juurest: `node tiktok-shared/export.js isa-tyybid`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Kriidijoonistuse stiil. Äratundmine ja sildistamine („milline on sinu isa?“); bränd ja hind alles viimasel slaidil. Isadepäev on 8. novembril 2026.

## Postituse tekst

> Milline neist on sinu isa? 😂 Märgi oma isa või õde-venda 👇
> #isadepäev #eesti #lauluhing

## Kuidas postitada

1. Lisa TikToki äpis populaarne, rõõmus heli.
2. Postita õhtul (u 19–21) ja kinnita oma kommentaar, nt „Minu isa on 100% sauna-isa 🔥“.

## Avaldamise seaded (WoopSocial, TikTok)

```json
{
  "postType": "PHOTO",
  "postMode": "MEDIA_UPLOAD",
  "privacyLevel": "PUBLIC_TO_EVERYONE",
  "allowComment": true,
  "autoAddMusic": false,
  "isYourBrand": true,
  "isBrandedContent": false,
  "photoCoverIndex": 0
}
```
