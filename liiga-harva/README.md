# TikTok Photo Mode: „Asjad, mida me ütleme liiga harva“

5 slaidi, 3:4 (1080×1440), tekst TikToki turvaalas. Allikas: `src/slides.html` (joonistused `tiktok-shared/crayon.js`, font `tiktok-shared/fonts/kalam.ttf`), eksport repo juurest: `node tiktok-shared/export.js liiga-harva`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Kriidijoonistuse stiil, üldine (sobib igal ajal, igale lähedasele). Postitus, mida saadetakse edasi; bränd ainult lõpus. Hinda ei näidata.

| # | Tekst | Joonistus |
|---|-------|-----------|
| 1 | ASJAD, MIDA ME ÜTLEME LIIGA HARVA | Inimene ja tühi jutumull „…“ |
| 2 | „Aitäh.“ Mitte poe kassas. Päriselt. | Lill vanemale inimesele |
| 3 | „Ma olen sinu üle uhke.“ | Isa ja medaliga laps, „TUBLI!“ |
| 4 | „Ma armastan sind.“ Ilma põhjuseta. | Kaks inimest, suur süda |
| 5 | Kui öelda on raske, ütle seda laulus. Praegu on soodushind! Kirjuta mulle TikToki sõnumitesse või lauluhing@gmail.com | Laulukaart „Laul sulle“ |
