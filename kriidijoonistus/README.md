# TikTok Photo Mode: „Kuidas teha kink, mida mäletatakse“ (kriidijoonistus)

5 slaidi, 9:16 (1080×1920), tekst TikToki turvaalas. Allikas: `src/slides.html` (fondid `tiktok-shared/fonts/kalam.ttf`, `permanentmarker.ttf`), eksport repo juurest: `node tiktok-shared/export.js kriidijoonistus`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

Stiil on omaniku saadetud eeskuju järgi: valge taust, käsitsi kirjutatud vildikiri (must + punane), värvipliiatsiga kritseldatud lapselik joonistus ja käepide all keskel. Joonistused on koodiga genereeritud (`src/slides.html` lõpus olev väike joonistuskomplekt: värvipliiatsi täidis kujundi sees + värisev kontuur), nii et neid saab muuta ja uusi slaide samas stiilis lisada.
