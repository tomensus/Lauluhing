# TikTok Photo Mode: „Eesti jõulud: vali üks“

7 slaidi, 9:16 (1080×1920), tekst TikToki turvaalas. Allikas: `src/slides.html` (ühine stiil `tiktok-shared/lauluhing.css`), eksport repo juurest: `node tiktok-shared/export.js vali-yks`. `safe-zone-check.png` näitab TikToki kasutajaliidese alasid sinisega, seda ei postitata.

## Miks see peaks vaatamisi saama

- **Kommentaarid:** iga vastaja kirjutab kommentaari 6 tähte (nt „ABBABB“). See on lihtsaim võimalik kommentaar ja TikTok loeb kommentaare tugevaks signaaliks.
- **Vaidlus:** verivorst pohlamoosiga või ilma, päris või plastkuusk, kingid õhtul või hommikul – eestlased vaidlevad nende üle päriselt, ja kommentaarides vaieldakse teiste vastustega.
- **Lõpuni libistamine:** vastuse kirjutamiseks tuleb kõik 6 valikut läbi vaadata.
- **Ei näe välja nagu reklaam:** logo ja bränd on ainult viimasel valikul (sokid vs laul tema enda loost), naljana.

## Postituse tekst

> Kirjuta oma 6 vastust kommentaari 👇 Verivorst ilma moosita on kuritegu, muutke minu meelt 😤
> #jõulud #eesti

## Kuidas postitada

1. Lisa TikToki äpis populaarne heli (mitte automaatne muusika).
2. Postita õhtul (u 19–21).
3. Kinnita esimesena oma kommentaar, nt „Mina: AABAAB. B kuusk, sest keegi ei viitsi okkaid korjata 😅“, ja vasta esimese tunni jooksul kommentaaridele (eriti vaidlustele).

## Avaldamise seaded (WoopSocial, TikTok)

```json
{
  "postType": "PHOTO",
  "postMode": "MEDIA_UPLOAD",
  "privacyLevel": "PUBLIC_TO_EVERYONE",
  "allowComment": true,
  "autoAddMusic": false,
  "isYourBrand": true,
  "isBrandedContent": false,
  "photoCoverIndex": 0
}
```
